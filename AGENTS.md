# DNA Crypto project rules
- Python project. Files: dnacrypto/encoding.py (bytes <-> DNA letters), dnacrypto/crypto.py (lock/unlock with AES-GCM), main.py (demo), tests/.
- Do NOT change existing functions in encoding.py or crypto.py unless I ask.
- Crypto: only use the `cryptography` library. Never write your own cipher. Never reuse a nonce.
- Work on ONE task at a time. Only create or edit the files I name.
- After any change, run `python -m pytest` and report the result.
- Do not install new packages unless I ask.
